Kapitel 1: Praktisk information

Servern är fokuserad på simplicitet! Inga hårda regler eller stora speländrande plugins används.

Pluginen som används:

CoreProtect för att skydda mot förstörelse

DiscordSRV för integration mot Discord

DriveBackup för automatiska säkerhetskopior

MinecraftStats för att kunna visa statistik per spelare

PictureLogin fär att visa ett informellt meddelande i chatten varje gång någon loggar in
